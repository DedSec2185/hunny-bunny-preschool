This Master Service Agreement (“Agreement”) is entered into between ASVEX Technologies (“Service Provider”) and Hunny Bunny Pre-School & Daycare (“Client”). The Service Provider has engineered, deployed, and configured the custom cloud-based institutional platform at hunnybunnypreschool.com to replace legacy web setups with an enterprise-grade digital acquisition system, end-to-end technical SEO, and Google local search optimization.
1. Scope of Work & System Deliverables

The Service Provider has engineered and successfully deployed a full-stack, mobile-first cloud web platform comprising the following core modules:

Module 1 — Custom Domain Acquisition & Cloud DNS Routing: Commercial purchase and configuration of the official hunnybunnypreschool.com domain on Hostinger, cloud DNS zone routing (A and CNAME records), automated 256-bit SSL/TLS encryption, and canonical www forwarding.
Module 2 — 24/7 Cloud Server Infrastructure & Global CDN: Serverless edge deployment on Vercel's global infrastructure with automated GitHub CI/CD, sub-50ms TTFB latency across India, DDoS security, and 99.99% high-availability uptime.
Module 3 — Technical, On-Page & Mobile SEO Architecture: 7 mobile-optimized custom pages with Schema.org JSON-LD microdata (Preschool, LocalBusiness, FAQPage, ContactPage), dynamic sitemap.xml with search priority tagging, robots.txt crawler directives, and WhatsApp OpenGraph preview cards.
Module 4 — Google Search Console Verification & Google Business Profile Optimization: Ownership verification via DNS TXT and HTML meta tags, sitemap indexing submission (7 URLs), priority crawl dispatch, Google Business Profile (GBP) manager synchronization, and updating description with official intake policies (December admissions, June–April term, strictly 20-student batches).
Module 5 — Interactive Guided Tour Booking & Parent QR Review Portal: Lead generation engine with Formspree email dispatch, WhatsApp direct-connect API, and a dedicated parent review portal (/review) with 5-star feedback rating interface.
2. Technical Infrastructure & 24/7 Cloud Hosting

The system is deployed on modern cloud architecture ensuring high availability and zero ongoing local maintenance overhead:

• Hosting Platform: High-performance serverless cloud edge infrastructure on Vercel with automated SSL/TLS (HTTPS) encryption certificates.
• Domain Engine: Managed Hostinger DNS zone configured with Vercel edge IP clusters.
• Universal Accessibility: Accessible 24/7 from any web browser on desktop computers, laptops, iPads/tablets, and smartphones worldwide without requiring local server hardware or manual maintenance.
